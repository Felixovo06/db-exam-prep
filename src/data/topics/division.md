### 一、先搞懂：除法到底在回答什么问题？

除法只回答一类问题：**“……全部……”**——例如“选修了**全部**课程的学生”“使用了**所有**指定零件的工程”。

设被除数 $R(X,Y)$，除数 $S(Y)$，其中 $Y$ 是两者的**公共属性**，$X$ 是 $R$ 独有的属性。则

$$R\div S=\{\,x \mid (x \text{ 在 } R \text{ 中出现})\ \wedge\ \Pi_Y(S)\subseteq Y_x\,\}$$

其中 $Y_x=\{\,y \mid (x,y)\in R\,\}$ 叫做 $x$ 的**象集**（$x$ 在 $R$ 里对应的所有 $y$ 值）。

用人话说：**把 $R$ 按 $X$ 分组，哪一组的 $Y$ 值把 $S$ 的 $Y$ 值“一个不漏”地包含了，这个 $X$ 就进入结果。**

| 项目 | 结论 |
|---|---|
| 结果的属性 | 只有 $X$（被除数独有的属性），公共属性 $Y$ 被“消掉” |
| 结果的行 | 满足“象集 ⊇ 除数”的那些 $x$（自动去重） |
| 是否满足交换律 | **不**满足，$R\div S\ne S\div R$ |

### 二、手算“象集法”四步（考场零失误）

1. **找属性**：写出 $R$ 有而 $S$ 没有的属性，这就是结果表头 $X$；两表同名的属性是公共属性 $Y$。
2. **求除数的投影**：写出 $\Pi_Y(S)$，即 $S$ 在公共属性上的所有取值（去重）。
3. **按 $X$ 分组求象集**：把 $R$ 中 $X$ 取值相同的行分为一组，写出每组的 $Y$ 值集合。
4. **逐组比较**：象集**完全包含** $\Pi_Y(S)$ 的那组，把对应的 $x$ 写进结果；有一个没包含就整组淘汰。

### 三、例题精讲

#### 例 1（最基础：一个公共属性）

$R(A,B)$ 与 $S(B)$ 如下，求 $R\div S$。

| R: A | R: B |
|---|---|
| $a_1$ | $b_1$ |
| $a_1$ | $b_2$ |
| $a_1$ | $b_3$ |
| $a_2$ | $b_1$ |
| $a_2$ | $b_3$ |
| $a_3$ | $b_2$ |

| S: B |
|---|
| $b_1$ |
| $b_2$ |

**解**：
1. 结果属性是 $A$，公共属性是 $B$；
2. $\Pi_B(S)=\{b_1,b_2\}$；
3. 象集：$a_1\to\{b_1,b_2,b_3\}$，$a_2\to\{b_1,b_3\}$，$a_3\to\{b_2\}$；
4. 比较：$\{b_1,b_2,b_3\}\supseteq\{b_1,b_2\}$ ✔；$\{b_1,b_3\}$ 缺 $b_2$ ✘；$\{b_2\}$ 缺 $b_1$ ✘。

所以 $R\div S=\{a_1\}$。

#### 例 2（真实场景：选修了全部指定课程）

学生选课关系 $SC(Sno,Cno)$：

| Sno | Cno |
|---|---|
| s1 | c1 |
| s1 | c2 |
| s1 | c3 |
| s2 | c1 |
| s2 | c2 |
| s3 | c1 |
| s3 | c3 |

求“选修了 c1 **和** c2 两门课的学生学号”。

**写表达式**：先用选择把“要求的课程集合”造出来作除数，再相除：
$$\Pi_{Sno,Cno}(SC)\div \Pi_{Cno}\big(\sigma_{Cno='c1'\vee Cno='c2'}(C)\big)$$

**手算**：除数 $=\{c1,c2\}$；象集 $s1\to\{c1,c2,c3\}$ ✔，$s2\to\{c1,c2\}$ ✔，$s3\to\{c1,c3\}$ ✘（缺 c2）。

结果：$\{s1,\ s2\}$。

> 注意：这里条件用的是 **∨（或）**。它的作用是把两门课**都收进除数集合**；“两门都选了”这层含义是由**除法本身**表达的。写成 $Cno='c1'\wedge Cno='c2'$ 会得到空集。

#### 例 3（选修了“全部”课程，除数是整张表）

$$\Pi_{Sno,Cno}(SC)\div\Pi_{Cno}(C)$$

只要把例 2 的除数换成整张课程表的 $Cno$ 列，就是“选修了**所有**课程的学生”。如果学校开了 $c1,c2,c3$ 三门课，则只有 $s1$ 满足。

#### 例 4（多个结果属性、除数含多列）

$S(A,B,C)$ 与 $T(B,C,D)$，求 $S\div T$（对应真题 2023 秋）：
- 公共属性 $Y=(B,C)$，结果属性 $X=A$；
- $\Pi_{B,C}(T)$ 是两个二元组，$S$ 中哪个 $A$ 对应的 $(B,C)$ 集合同时包含这两个二元组，哪个 $A$ 才入选；
- 除数的投影可以是多列，比较的是**整个二元组**，而不是某一列。

### 四、考场写关系代数查询的套路

| 题目中的关键词 | 用什么 |
|---|---|
| “**全部**/**所有**/**每一个**……的” | 除法 |
| “至少选修了 **A 和 B**” | 除法（或两个选择结果取交集 $\cap$） |
| “选修了 A **或** B” | 选择里用 ∨，不需要除法 |
| “**没有**选修……的” | 差 $-$：先求全体，再减去选了的 |

**写除法表达式的 3 条铁律：**
1. 被除数只投影“结果属性 + 除数属性”，**不要带多余列**（如 `Grade`），否则分组会被多余列打散；
2. 除数要先投影成只含公共属性的一列（如 $\Pi_{Cno}(\dots)$）；
3. 想不起来除法时，可以改用“**交集法**”：分别求出“选了 A 的学生集合”和“选了 B 的学生集合”再取交。

### 五、易错点速查

- 除法结果里**没有**公共属性，也没有除数独有的属性；
- 象集必须**全部包含**，包含一部分不给分；
- 除数为空集时除法没有意义，考试不会出现；
- 把“除”写成差集 SQL 或自然连接是典型错误。
