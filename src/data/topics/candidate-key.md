### 一、预备概念

- **函数依赖** $X\to Y$：只要 $X$ 的取值相同，$Y$ 的取值就一定相同（$X$ 决定 $Y$）。
- **属性集闭包** $X^+$：由 $F$ 能推出的、被 $X$ 决定的全部属性。
- **候选码**：能决定全部属性 $U$ 的**最小**属性集（$X^+=U$，且去掉其中任何一个属性都不再成立）。
- **主属性**：出现在任意一个候选码中的属性；其余叫**非主属性**。
- **超码**：能决定全部属性的属性集（候选码的超集）。

### 二、求属性闭包 $X^+$（所有题的基础）

算法（“滚雪球”）：
1. 令 $X^+ = X$；
2. 扫描 $F$ 中每条 $L\to R$：若 $L\subseteq X^+$，就把 $R$ 并入 $X^+$；
3. 重复第 2 步，直到 $X^+$ 不再变化。

**例**：$F=\{A\to B,\ BC\to D,\ D\to E\}$，求 $(AC)^+$。
- 初始 $\{A,C\}$；
- $A\to B$：$A\in$ 集合，加入 $B$ → $\{A,B,C\}$；
- $BC\to D$：$B,C$ 都在，加入 $D$ → $\{A,B,C,D\}$；
- $D\to E$：加入 $E$ → $\{A,B,C,D,E\}$；
- 不再变化，$(AC)^+=ABCDE$。

### 三、求候选码：L / R / N / LR 四类分法

把所有属性按它们在 $F$ 中出现的位置分成四类：

| 类别 | 含义 | 结论 |
|---|---|---|
| **L 类** | 只出现在依赖的**左边** | 一定在**每个**候选码中 |
| **R 类** | 只出现在依赖的**右边** | **一定不在**任何候选码中 |
| **N 类** | 在 $F$ 中**从未出现** | 一定在每个候选码中 |
| **LR 类** | 左右两边都出现过 | 不确定，需要尝试 |

**求解流程**：
1. 先取 $L\cup N$ 作为“核心”，计算 $(L\cup N)^+$；
2. 若 $(L\cup N)^+=U$，则 $L\cup N$ 就是**唯一候选码**，结束；
3. 否则，依次尝试在核心上加入 **1 个** LR 类属性，算闭包；能得到 $U$ 的就是候选码；
4. 若 1 个不够，再试加 **2 个**……注意：已经是候选码的组合，其超集**不再算候选码**（不满足最小性）。

### 四、例题精讲

#### 例 1：唯一候选码（链式依赖）

$R(A,B,C,D)$，$F=\{A\to B,\ B\to C,\ C\to D\}$。

- L 类：$A$（只在左边）；R 类：$D$（只在右边）；LR 类：$B,C$；N 类：无。
- 核心 $=\{A\}$：$A^+=\{A,B,C,D\}=U$ ✔

**候选码：$A$（唯一）**。主属性 $\{A\}$，非主属性 $\{B,C,D\}$。

#### 例 2：多个候选码（循环依赖）

$R(A,B,C)$，$F=\{AB\to C,\ C\to A\}$。

- L 类：$B$；R 类：无；LR 类：$A,C$。
- 核心 $\{B\}$：$B^+=\{B\}\ne U$，需要加 LR 属性：
  - $\{A,B\}$：$AB\to C$ → $\{A,B,C\}=U$ ✔ **候选码 $AB$**；
  - $\{B,C\}$：$C\to A$ → $\{A,B,C\}=U$ ✔ **候选码 $BC$**。

**候选码：$AB$ 和 $BC$**。三个属性都是主属性。

#### 例 3：含 N 类“孤立”属性

$R(A,B,C,D,E)$，$F=\{A\to B,\ C\to D\}$。

- L 类：$A,C$；R 类：$B,D$；N 类：$E$（从未出现）。
- 核心 $=L\cup N=\{A,C,E\}$：$(ACE)^+=\{A,B,C,D,E\}=U$ ✔

**候选码：$ACE$（唯一）**。N 类属性 $E$ 千万不能漏。

#### 例 4：所有属性都是 LR（全码循环）

$R(A,B,C)$，$F=\{A\to B,\ B\to C,\ C\to A\}$。

- 三个属性都既在左又在右，核心为空，逐个试：$A^+=ABC$，$B^+=ABC$，$C^+=ABC$。

**候选码：$A$、$B$、$C$（各自单独就是候选码）**。

#### 例 5：真题套路（带复合依赖）

$R(A,B,C,D,E)$，$F=\{AE\to D,\ D\to A,\ DE\to B,\ B\to D,\ C\to D\}$（2023 秋真题）。

- 出现在右边的有 $D,A,B$；$C$ 和 $E$ 从未出现在右边 → 它们是 L 类（或 N 类），一定在候选码中；
- 核心 $\{C,E\}$：$C\to D$ 得 $D$；$D\to A$ 得 $A$；$DE\to B$ 得 $B$ → $(CE)^+=ABCDE=U$ ✔

**候选码：$CE$（唯一）**。

### 五、常见坑点与技巧

1. **别漏 N 类**：题目里偶尔有个属性没出现在任何依赖里，它必在每个候选码里；
2. **R 类一定不是主属性**，这条能立刻排除很多属性；
3. 核心闭包已是 $U$ 就可以立刻停止，不要再试 LR 类；
4. 多个候选码时要**全部写出**；
5. 验证最小性：候选码中去掉任一属性后闭包都不再是 $U$；
6. 复习闭包的另一用途：判断 $X\to Y$ 是否成立，只需看 $Y\subseteq X^+$。
